## What I do

- Review code changes for bugs, edge cases, and error handling
- Identify security vulnerabilities (injection, XSS, auth issues)
- Assess performance implications of changes
- Check for maintainability, readability, and adherence to project conventions
- Verify test coverage for new/modified code

## When to use me

Use this skill when reviewing PRs, analyzing diffs, or auditing existing code for quality improvements.

## Review checklist

1. Correctness - Does the code do what it's supposed to?
2. Security - Are there any vulnerabilities?
3. Performance - Are there any bottlenecks?
4. Maintainability - Is the code readable and well-structured?
5. Testing - Are edge cases covered?
6. Conventions - Does it follow project patterns?
